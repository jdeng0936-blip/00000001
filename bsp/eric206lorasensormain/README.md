# eric206\_lora\_sensor\_main

#### 介绍

Eric206 Lora版本 sensor主机程序

#### 软件架构

无主机情况下会接收数秒后睡眠15分钟以节约电池

有主机情况下会根据主机广播的时间信息进行睡眠省电

当确定到自身的工作时间窗口时会回复信息更新在线状态并按照长短包设置进行睡眠和唤醒操作

短包唤醒时不会读取波形数据，长包唤醒时会读取波形数据，所以两种情况下的工作时长不同

#### 安装教程

1. 烧录
2. 写ID和频道

#### 使用说明

1. ID和频道需要预先写入
2. 是否使用转发器与传感器无关
