## 先读这一段

**为什么要人去看**：做资料的那一轮，会话网络打不开 moj.go.jp、mhlw.go.jp、nenkin.go.jp、city.osaka.lg.jp、police.pref.osaka.lg.jp、npa.go.jp 等多数官方网站，很多文字来自搜索摘录。用自己的手机或电脑打开就行。

**每一条都要交回这些东西**（缺一样就算没核完）：

| 项 | 写法 |
|---|---|
| 行号 | 例：`0-1｜费用和经济条件`（节点编号＋要点的名称，和下面每条的标题一样） |
| 核对日期 | `2026-12-03` 这样的写法 |
| 方式 | 网页／电话／窗口／门店，写清是哪个（网址、哪个区役所、哪家门店、对方的部门名；不用记对方的姓名） |
| 原文 | 网页：把相关的那一两句**日文原文**复制下来；电话、窗口：照对方说的记下来，写明“口头” |
| 金额、日期 | 照原样记，带单位（日元、含税或不含税）和适用日期（“2026年4月1日起”） |
| 证据 | 网页截图（要能看到网址和页面上的日期或更新日）；PDF 下载下来，记下文件上印的日期或版本；门店、窗口拿到的纸质资料拍照 |
| 和 App 的出入 | 一致／不一致（不一致的写出哪里不一样） |

**注意**：
- 问门店、中介、银行时**不要报自己或别人的真实个人信息**，按“假设一个刚来大阪、拿工作签证的中国人”来问就行。不要把在留卡号、护照号、账号发给任何人。
- 只记事实，不要替 App 下结论；对方说法和网页不一致时，两样都记下。
- 网页上找不到时，也要交回：写“这个页面没有写这一项”，附截图和网址。这个结果同样有用。

**交回以后**：交给开发。开发按记录改 `data/nodes.json` 那一行的文字、出处（`src`）和节点的核对日期（`checked`），改完运行 `npm test`，并更新 `docs/compliance-review.md` 第二、四节的计数。是否把一行改成“已核实”（第 3 项从 0 改成 1）：按现有规则，只有至少一个官方来源支持的才能改成已核实；中介、门店、银行、汇款公司、驾校这类商业信息，开发把金额和查阅日期写进文字，改不改成已核实由负责人定。

- **注意**：这是商业价格，交回时写明“3 家的例子”，不要算成平均数。

### 15. `2-2｜没有银行卡时的缴费方式`（电话卡）

- **App 现在写的**：缴费方式因运营商和套餐而不同；部分套餐只接受和签约人同名的银行账户扣款或信用卡（例：ahamo 是信用卡或账户扣款，名义须和签约人相同）；没有银行账户或信用卡时，可向门店确认是否有账单缴费、便利店缴费或预付式服务，以及是否另收手续费（待实测）。节点的“费用”写着“按套餐，月费待实测”。
- **去哪里**：大阪市内 docomo、au、SoftBank、楽天モバイル 各一家门店（或官网的“支払い方法”页面加门店确认）；ahamo 官网的支付方式页。
- **记下**：每家：没有银行账户和信用卡能不能签约；能用的支付方式（请求书払い、コンビニ払い、预付等）；有没有手续费、每月多少；需要的证件；门店名称、日期；官网支付方式页的截图和网址。

### 16. `2-3｜各银行的实际受理情况`（银行卡）

- **App 现在写的**：各银行对在留期限剩余期间、在留资格、入境时长等各有规定，可能因分店而异；邮储银行公开写明：在留期限在申请日起 3 个月内到期的不予开户，入境时决定的在留期间在 3 个月以下、没有在留卡的也不能开户；其他银行请在申请前向分店确认（待实测）。
- **去哪里**：
  1. 邮储银行 致外国人客户：https://www.jp-bank.japanpost.jp/kaisetu/kat_gaikokujin.html ，核对上面那两条的原文。
  2. 三菱UFJ、三井住友、りそな 在大阪市内的分店各一家（电话或窗口），问：「入国して6か月未満の外国人（就労ビザ）は口座を開設できますか。在留期限の残りが何か月以上必要ですか。必要な書類は何ですか（在留カード、マイナンバー、勤務先の書類、電話番号など）。」

- **注意**：只记银行怎么说，不要替银行解释外汇法上的“居住者”问题（那一行 `2-3｜入境未满6个月` 是“官方未公布”，不在这份清单里）。

### 17. `4-9｜银行、电话、房屋`（回国和长期离开日本）

- **App 现在写的**：银行、电话、房屋、水电燃气各自按合同解约并结清；房屋提前多久通知以租赁合同为准；银行账户是否需要销户、离开日本后还能不能用，请向自己的银行确认。

- **记下**：每家银行的回答（要不要销户、出国后能不能用、有什么手续）；中介说的一般解约通知期；日期和对象。

### 18. `4-10｜年度中途入所`（保育所申请）
